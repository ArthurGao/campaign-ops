为什么放在同一个文件里，但分成两页

预算和目标不会出现在任何对外内容里，但决定了方案怎么做。放在同一个文件里，所有待确认的事都在一处；分成两页，是为了出稿 Agent 只拿到对外页，看不到内部数字。

  • 用销售目标倒推：所需有效咨询数 ≈ 目标席位数 [N] ÷ 平均每单人数 [p] ÷ 有效咨询到订单的成交率 [r]。这几个数没确认前都算假设，不填编造的数字。算出来再和现有渠道大概能带来的量比一比，就知道缺口多大、要不要花钱买
  • 销售接得住的量是上限：缺口再大，每周买来的咨询也不超过销售跟得过来的量
  • 预算决定广告做不做、先投哪个渠道
  • 第 4 周复盘时看样本量和销售周期：样本够了就用实际成交率替换假设值重算缺口，不够就保留假设，不下确定结论

    • 对外发布或花钱之前

    • 事实变了、线上和批的不一致、追踪断了、重试次数用完
    • 销售说的和数据对不上

    放手让它跑

    • 诊断 Agent 的只读检查
    • 出稿 Agent 在确认过的事实范围内起草和初步验收
    • 视频工厂在额度内生产和重试

    怎么协调三方

    启动会上请客户批一个预批范围：预算上限、什么情况暂停、能用的素材和信息范围、哪些非实质小改可以由我批。范围内我直接安排，只有超出范围才再找客户。此外客户主要在两个地方见到我：确认事实和预算、批具体版本；另外每周一次集中审批，加一页周报。执行人只接批过的任务卡，Agent 只接我派的活。三方不直接互相派活，免得绕过审批。

    怎么避免重复造轮子

    先把客户和 Magic Engine 已有的系统列出来（网站后台、GTM、CRM、排期工具、视频工厂），只在它们之间缺衔接的地方用 Agent 或集成工具补上。追踪、发布、视频都不另外开发一套。

    • 平台后台只能下载最近 90 天的线索。同步断了当天就手动补导，不能等月底

    • 和官网表单、私信按邮箱或电话去重，规则同 CRM 表

    • CRM 是唯一的账，一个咨询只记一条，只算给一个来源
    • 归因规则提前约好，比如 last non-direct click；首次来源也留着，用来看哪些渠道擅长让人第一次知道我们

    • branded search 广告单独看，它常常抢走本来会从 organic search 来的咨询
    • 每周对账：各平台报的 conversions 加起来，和 CRM 实际数比一比，记下高估了多少

    题目第七部分，四选二。我准备的是第 1 题和第 3 题。

    AI 在线路页文案里承诺了未经确认的签证政策和团期，怎么办
    • 先止损：页面内容用网站后台、CMS 或部署版本回滚到批准版本，追踪配置才用 GTM 的版本回滚；回不去就先下线或设私密；引用了同一说法的帖子和广告一起处理，指向这个页面的广告先暂停
    • 查范围：按 Fact Sheet 编号找引用过的内容；但 AI 编的说法可能根本没有编号，所以同时按错误原文、关键词、素材字幕和发布日志再搜一遍（视频、配文、广告、其他页面），逐个检查
    • 告诉客户：什么时候上线的、大概多少人看到、已经怎么处理。如果有人据此咨询了，销售统一口径回复“以官方信息为准”，并给出正确说法
    • 查是哪一步没拦住：出稿 Agent 没标“需确认”？验收没核签证和团期？还是批的版本和上线的不一致？找到那一步，补一道检查
    • 加硬规则：签证、团期、价格这类内容，Agent 指令里写明“没有 Fact Sheet 编号一律不写”；验收清单里这几项必须人看过才能过

    一句话：不是 AI 的问题，是流程哪一步没拦住；先止损，再补那一步。

    广告产生了线索，但客户说这些人不适合，AI 怎样辅助诊断
    • 先把“不适合”写清楚：和销售一起给这批线索标无效原因，比如预算不够、想自由行、时间不对、没看懂产品。没有原因，AI 没法分析
    • 让回流 Agent 做三件事：按原因分类；对照每条线索的来源（哪条广告、哪个 audience、哪个关键词、哪个版本的 landing page）；找共同点
    • 顺着原因找根源：多数是“没看懂产品”，查广告文案和页面说法有没有误导；多数是“想自由行”，audience 或关键词太宽；多数是“预算不够”，价格区间没在前面说清楚
    • 一次只改一件事，到下一个复查点（一般两周，样本不够就再等）看有效率有没有变：比如先收窄关键词，或者在 landing page 前面放价格区间
    • 把有效和无效的结果回传平台（Conversions API、offline conversions），让平台往质量优化；持续产生无效线索的广告组直接停

    AI 的边界：Agent 做分类和对照，线索适不适合由销售判断，改什么由我定。
